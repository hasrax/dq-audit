# ClarityDQ

ClarityDQ is an explainable data quality audit tool for small and medium-sized businesses that use ERP systems. It reads ERP data exports and finds problems such as missing, wrong, duplicated or inconsistent values. It does this in two ways: automatic rules that check every row, and an AI auditor that looks at a small, privacy-masked sample for problems rules can't express. Every issue is explained in plain English, with what was found, why it matters and what to do.

A non-technical reviewer can accept, reject or mark each issue as unsure, ask questions about it in a chat, and download reports. The tool also tracks a data quality score over time. ClarityDQ was built as a final-year BSc (Hons) Computing research project (Coventry University / NIBM), using Python, PostgreSQL and Streamlit.
